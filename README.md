# OdoLog 🚗💨

OdoLog is a sleek, open-source, mobile-first Progressive Web App (PWA) designed for seamless multi-vehicle tracking, detailed fuel-efficiency metrics, and automated travel expense logging. Built around rapid micro-interactions and high portability, it empowers owners to completely audit their vehicle health, running costs, and regional financial trends.

🔗 **Live Demo:** [https://odolog.online](https://odolog.online)

---

## ✨ Features (New in V2.0.0!)

OdoLog has evolved into a full-scale automotive management hub:

*   📊 **Advanced Analytics & Trips:** Built-in Trip Logger tracking per-trip costs, purposes, and distances, paired with dynamic analytics, next-trip predictions, and running costs per vehicle.
*   🔌 **EV & Alternate Fuel Flow:** Tailored experiences for electric cars, scooters, and bikes—complete with custom EV-only maintenance presets (brakes, tyres, battery; no engine oil parameters), a green savings calculator, and CNG integration.
*   ⚡ **Data Portability:** Sophisticated CSV/JSON import engines supporting automated column auto-detection and manual remapping for data coming from Fuelio, Drivvo, aCar, and Hammond.
*   📅 **Smart Integrations & Alerts:** Google Calendar OAuth synchronization for automated maintenance/PUC/insurance expiry count-downs, alongside an active Weather Chip providing contextual safety advisories via Open-Meteo.
*   📉 **Financial Intelligence:** Integrated reducing-balance depreciation toggles (15%/yr cars, 12%/yr two-wheelers), ARAI-claimed mileage vs. actual efficiency deltas, and regional single-city fuel type cost history analysis.
*   🎨 **Polished UX/UI:** Overhauled light mode (warm stone/aurora), fluid glassmorphism layout components, strict sequential ODO mileage validation logic, and full PWA compatibility for a native-app feel on mobile or desktop viewports.

## 🛠️ The Stack & Ecosystem

*   **Runtime & Tooling:** Bun runtime environment, Vite build tooling
*   **Frontend Framework:** React with TypeScript, Tailwind CSS, Shadcn UI
*   **Backend Database:** Supabase (PostgreSQL)
*   **App Standard:** Full Progressive Web App (PWA) Manifest

---

## 🗺️ What's Next for OdoLog

OdoLog will remain **100% free and open-source**, focusing on delivering a premium mobile-first dashboard experience completely free of cost. The roadmap includes deeper multi-vehicle cross-comparisons, proactive automated notifications, and direct OBD (On-Board Diagnostics) adapter integrations.
